# 🚀 我的 Hexo 博客诞生记

今天成功在 Mac 上搭建了 Hexo 博客！

## 📦 环境配置

### 安装的工具
- **Node.js** - JavaScript 运行环境
- **Git** - 版本控制
- **Hexo** - 静态博客框架
- **VS Code** - 代码编辑器

### 关键命令记录

```bash
# 安装 Hexo
npm install -g hexo-cli

# 初始化博客
hexo init my-blog

# 启动本地预览
hexo server
